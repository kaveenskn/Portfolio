
# Kaveen | Creative Developer Portfolio

> A visual portfolio for building useful digital experiences with thoughtful interfaces, motion, and a little bit of wonder.

This is the personal portfolio of **Kaveen**, a creative developer interested in the space where design, code, and intelligent systems meet. The site is designed as an interactive journey rather than a collection of static pages: scroll through the story, explore projects inside a laptop-inspired showcase, and discover the skills hanging in the workspace.

## What is inside

- A cinematic, responsive hero experience for desktop and mobile
- About, projects, skills, contact, and social sections in one flowing page
- Animated scroll reveals and tactile hover interactions
- Responsive project browsing with desktop pagination and mobile controls
- A curated collection of web apps, mobile apps, UI explorations, and AI experiments

## Built with

`React` · `TypeScript` · `Vite` · `Tailwind CSS` · `Framer Motion` · `GSAP` · `Three.js` · `Lucide React`

## Run locally

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open the local URL shown in the terminal.

## Available scripts

```bash
npm run dev      # Start the Vite development server
npm run build    # Type-check and create a production build
npm run lint     # Check the codebase with ESLint
npm run preview  # Preview the production build locally
```

## Design direction

The portfolio treats the interface as part of the work: dark editorial surfaces create focus, large imagery gives each project room to breathe, and motion provides a sense of continuity while navigating the page. The result is meant to feel personal, exploratory, and direct.
